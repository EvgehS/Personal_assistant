# 🗣️ Голосовой ассистент для Linux с локальным ИИ-поиском

## 📌 Цель проекта

Разработка голосового ассистента для Linux-систем, способного:
- Распознавать голосовые команды
- Выполнять базовые системные действия
- Инициировать локальный поиск информации с помощью нейросетевых моделей (LLM) без обращения к внешним API

---

## 🧠 Основные возможности

- 🎙️ **Голосовой ввод** — распознавание речи в реальном времени
- 🖥️ **Системные команды** — управление окнами, запуск программ, навигация по файлам и прочее
- 🔍 **Локальный ИИ-поиск** — ответы на вопросы через локально развёрнутую LLM (например, Mistral, LLaMA)
- 📦 **Модульность** — легко расширяемая архитектура с возможностью подключения новых модулей

---

## 🛠️ Технологии

| Подсистема | Технологии |
|------------|------------|
| Распознавание речи | Vosk |
| Нейросетевой ИИ | LM-Studio |
| Язык реализации | Python / C++ |
| Операционная система | Linux (Заточен преимущественно под Arch Linux) / MacOS (Пока под вопросом) |

## 🧠 Необходимые зависимости

Для корректной работы голосового ассистента требуется:

- ✅ Установленный Boost (библиотека C++). В Arch Linux: 
```bash
sudo pacman -S boost
```
- ✅ Установленный RHVoice (библиотека C++). В Arch Linux: 
```bash
sudo pacman -S rhvoice rhvoice-language-russian rhvoice-voice-vsevolod
```
- ✅ Установленный ffplay (библиотека C++). В Arch Linux: 
```bash 
sudo pacman -S ffmpeg
```
Если нужно воспроизводить с помощью другой утилиты то правьте исходники 😃 (Functions/Sounds/sound_functions.cpp ф-ия speak)
- ✅ Установленная программа LM Studio — для локального запуска языковой модели:

        Скачайте с официального сайта: https://lmstudio.ai

        Запустите LM Studio и загрузите нужную модель

git clone https://github.com/EvgehS/Personal_assistant.git

📦 **Подготовка окружения**

- В репозитории уже есть папка venv, но если ассистент с ней не работает, рекомендуется пересобрать виртуальное окружение. Для установки пакетов через pip требуется VPN:
 ```bash
 python -m venv --clear venv
 venv/bin/pip install --upgrade pip
 venv/bin/pip install -r requirements.txt 
 ```
 - Необходимо скопировать в venv/include/python3.13 заголовочные файлы из /usr/include/python3.13 (В общем случае путь может быть другой)
 ``` bash
 sudo cp -r /usr/include/python3.13/* venv/include/python3.13
 ```
- ⚠️ Обрати внимание: путь /usr/include/python3.13/ может отличаться в зависимости от системы. Уточни его с помощью команды:
```bash
python3.13-config --includes
```

⚙️ **Настройка .config.txt**

Создайте файл .config.txt на основе шаблона .config_example.txt

 - Для выбора подходящего аудиоустройства выполните:

```bash
venv/bin/python
```

Затем в интерактивной оболочке Python введите:

```python
import sounddevice as sd; sd.query_devices()
```

Скопируйте подходящий номер устройства из вывода и укажите его в поле sound_device файла .config.txt

🧾 Пояснения к параметрам:

- sound_device - получение номера описано выше

- compile_libs — библиотеки для компиляция python функции с помощью boost.
Основная задача — убедиться, что используются заголовочные файлы и библиотеки Python из виртуального окружения venv

- name — имя вашего ассистента. Указывается для обращения в речи и визуальных сообщениях

- default_model — название модели, которая используется для обычных (непрограммных) вопросов.
Рекомендуется выбрать компактную и быструю модель, подходящую под ваши задачи

- assistant_default_mode - режим работы ассистента по умолчанию
